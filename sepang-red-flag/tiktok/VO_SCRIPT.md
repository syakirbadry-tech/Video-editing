# Sepang red flag — voice-over script (English, ~65 s)

The preview carries an **AI stand-in voice** (`tiktok/voice.py`, Kokoro TTS run locally) so the edit can be
judged with narration. Each line has a delivery — excited, sad, confused — set by punctuation, speed and
pitch. Replace it with your own read whenever you like: the times below are where each line sits in the edit.

Read it with the same emotion marks. Leave a short beat where you see `/`. **Bold** = punch the word.

**Recording tips:** quiet room (a car or a wardrobe works well), phone 15–20 cm from your mouth,
Voice Memos at high quality. Do 2–3 full takes and upload them as `.m4a` (or `.wav`) to the same
Drive folder as the clips; the edit gets re-cut to your recording.
